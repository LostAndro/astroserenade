# False ID
A False ID provides fake identity information that can pass cursory inspection. A creature that examines the False ID realizes it’s a fake with an Intelligence (Investigation) check as a Study action, against the DC determined by the ID’s quality.

A Supreme quality False ID is backed up by implanted fake, or repurposed true, information in local databases.

### False ID

| Quality  | DC  | Cost      |
| -------- | --- | --------- |
| Standard | 15  | 500 GN    |
| Superior | 20  | 10,000 GN |
| Supreme  | 25  | 50,000 GN |
