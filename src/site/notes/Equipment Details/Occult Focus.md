# Occult Focus
An Occult Focus takes one of the forms in the Occult Focuses table and is bejeweled or worked to channel arcane magic. A Cryptist or Esper can use such an item as a Spellcasting Focus.

### Occult Focuses

| Focus   | Weight | Cost     |
| ------- | ------ | -------- |
| Circlet | 1 lb.  | 500 GN   |
| Crystal | 1 lb.  | 500 GN   |
| Diagram | 1 lb.  | 250 GN   |
| Orb     | 3 lb.  | 1,000 GN |
