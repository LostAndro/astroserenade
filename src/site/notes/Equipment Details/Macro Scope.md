# Macro Scope
A Macro Scope is an optical enhancer for viewing distant things. Standard, commercially available models allow detailed viewing out to double a user’s normal sight range. More expensive variant models add different functionality, such as longer range or vision modes.

As a Utilize action, you can fit a scope to a ranged weapon with the Two-Handed property. Ranged attack rolls with the weapon don’t have Disadvantage for firing at a target beyond normal range if you don’t move during the same turn.
