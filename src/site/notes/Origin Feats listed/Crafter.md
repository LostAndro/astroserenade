#### [[Origin Feats\|Origin Feats]]
# Crafter
Source: Player's Handbook
*Origin Feat*

You gain the following benefits.

***Tool Proficiency***. You gain proficiency with three different Crafter's Tools of your choice from the Fast Crafting table.

***Discount***. Whenever you buy a nonmagical item, you receive a 20 percent discount on it.

***Fast Crafting***. When you finish a Long Rest, you can craft one piece of gear from the Fast Crafting table, provided you have the Crafter's Tools associated with that item and have proficiency with those tools. The item lasts until you finish another Long Rest, at which point the item falls apart.

#### Fast Crafting

| Crafter's Tools       | Crafted Gear                                              |
| --------------------- | --------------------------------------------------------- |
| Construction Tools    | Ladder, Torch                                             |
| Engineer’s Tools      | Bell, Shovel, Tinder Box                                  |
| Mechanic’s Tools      | Ball Bearings, Bucket, Caltrops, Grappling Hook, Iron Pot |
| Polymer-Molding Tools | Jug, Lamp                                                 |
| Textile Tools         | Basket, Rope, Net, Tent                                   |
